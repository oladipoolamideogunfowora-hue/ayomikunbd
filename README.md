# Birthday Celebration Card — Ayomikun

A little flip-through interactive birthday card celebration featuring photos, heartfelt messages, background music, and confetti effects.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) / React 19
- **Routing**: TanStack Router
- **Styling**: Tailwind CSS v4
- **Animation**: Motion (Framer Motion)
- **Effects**: Canvas Confetti

## Getting Started

### Prerequisites

- Node.js (v18+ or v20+)
- npm or bun

### Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) to view it in the browser.

### Build for Production

```bash
npm run build
npm run preview
```

## Deployment to Netlify

This project includes a `netlify.toml` configuration ready for one-click deployment on Netlify.
